# Credit Risk Modelling — Loan Classification

A machine learning project that analyzes loan applicant data and applies classification algorithms to predict loan-related outcomes.

## Overview
This project uses data analysis and machine learning to explore loan applicant characteristics and build predictive classification models. It includes data preprocessing, exploratory analysis, feature engineering and model evaluation.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## Workflow
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Missing value and outlier analysis
- Class imbalance handling
- Feature selection and scaling
- Model training and evaluation

## Machine Learning Models
- Logistic Regression
- Decision Tree Classifier
- Gradient Boosting
- Random Forest

## Evaluation
Models are evaluated using classification metrics, confusion matrices and classification reports.
